## Publication sur GitHub Pages
1. Créez un dépôt public nommé `derekh`.
2. Déposez tous ces fichiers directement à la racine du dépôt.
3. Allez dans `Settings` > `Pages`.
4. Sélectionnez la branche `main` et `/ (root)`.
5. Enregistrez. Votre site sera en ligne à l'adresse : `https://VOTRE-PSEUDO.github.io/derekh/`
